Initializes a new wallet. The daemon generates a 24-word aezeed mnemonic,
prints it to stderr so you can record it offline, and encrypts the seed with
the supplied password. Pass `--recover` with a `--mnemonic-file` to import an
existing mnemonic and rebuild Ark wallet state instead.

The wallet password is never read from the command line, and stdin is never
consumed implicitly. It comes, in priority order, from the
`WAVED_WALLET_PASSWORD` environment variable, `--wallet-password-file`, an
explicit `--password-stdin`, or an interactive terminal prompt that asks for
confirmation. When none of those sources is available (non-interactive stdin
without `--password-stdin`, or input disabled via `--no-input` / `CI=true`)
the command exits `2` with instructions instead of hanging. The optional
aezeed seed passphrase comes from `WAVED_SEED_PASSPHRASE` or
`--seed-passphrase-file`.

```bash title="Terminal"
printf '%s\n' 'hunter2hunter2' | wavecli create --password-stdin
```

A wallet can also be built from keys you already hold, in two ways. They have
no mnemonic to show, and `--birthday` bounds the first rescan of each.

**From descriptors.** `--descriptor-file` builds the wallet from private output
descriptors, one per line. Blank lines and lines starting with `#` are ignored.
The file holds one of two forms:

- Descriptors that share one BIP32 master key: `tr()` under `86h/0h/0h` and
  `wpkh()` under `84h/0h/0h`.
- Account-level private keys, for keys exported from other software without the
  master key: the `tr()` account at `[fp/86h/0h/0h]`, optionally `wpkh()` at
  `[fp/84h/0h/0h]`, and the key families as one `[fp/1017h/COINh]xprv` line or
  one `[fp/1017h/COINh/FAMILYh]xprv/0/*` line for every family 0 to 255. `COIN`
  is `0` on mainnet and `1` elsewhere.

```bash title="Terminal"
wavecli create --descriptor-file wallet.descriptors --birthday 2026-01-01
```

**From a remote signer.** `--watch-only-bundle-file` creates a wallet that holds
public keys only, with every signature coming from the daemon's
`wallet.remotesigner`. A minimal bundle also holds the two authentication
families as private keys, so the daemon signs round joins and payment receipts
itself while every key that can move funds stays on the signer.
`--watch-only-manifest` does the same when each fund slot may come from a
different key, and needs `--auth-keys-file`. Export these with
[`wavesigner`](/cli/wavesigner/), or from an existing wallet with
[`export-watchonly`](/cli/export-watchonly/).

```bash title="Terminal"
wavecli create --watch-only-bundle-file signer.bundle --birthday 2026-01-01
wavecli create --watch-only-manifest wallet.manifest --auth-keys-file auth.keys
```

<Callout type="caution" title="The mnemonic is shown once">
On a fresh create the 24-word mnemonic is written to stderr exactly once and is
NOT included in the JSON response on stdout. Capture it from stderr, or pass
`--print-mnemonic-json` to opt into the machine-consumable form. Losing it makes
the wallet unrecoverable.
</Callout>

## Flags

| Flag | Default | Description |
|---|---|---|
| `--wallet-password-file` | (none) | Path to a file containing the wallet password. |
| `--password-stdin` | `false` | Read one wallet password line from stdin. |
| `--seed-passphrase-file` | (none) | Path to a file containing the optional aezeed passphrase. |
| `--print-mnemonic-json` | `false` | Include the mnemonic in the JSON response on stdout (default: stderr only). |
| `--recover` | `false` | Import an existing mnemonic and recover Ark wallet state. |
| `--mnemonic-file` | (none) | Path to a file containing an existing 24-word aezeed mnemonic. Requires `--recover`. |
| `--recovery-window` | `0` | Number of key indexes to scan per recovery family. Requires `--recover`; `0` uses the daemon default. |
| `--descriptor-file` | (none) | Path to a file of private output descriptors or account-level private keys, one per line, to build the wallet from instead of a mnemonic. |
| `--birthday` | (none) | Earliest date the descriptor or bundle keys may have received funds, as RFC 3339 or `YYYY-MM-DD`. Requires `--descriptor-file`, `--watch-only-bundle-file` or `--watch-only-manifest`. Without it the wallet scans from genesis. |
| `--watch-only-bundle-file` | (none) | Path to the remote signer's account public keys, for a wallet whose private keys stay on that signer. |
| `--watch-only-manifest` | (none) | Path to a key manifest assigning each fund slot its own public key. Requires `--auth-keys-file`. |
| `--auth-keys-file` | (none) | Path to the authentication families' private keys, for `--watch-only-manifest`. |
| `--override-identity` | `false` | Allow a `--watch-only-manifest` that replaces the identity family, which changes the wallet's Ark identity. |

## Example

```bash title="Terminal"
printf '%s\n' 'hunter2hunter2' | wavecli --no-tls create --password-stdin
```

The mnemonic goes to stderr; stdout carries the identity and recovery summary:

```json
{
  "identity_pubkey": "02a1b2c3d4e5f60718293a4b5c6d7e8f90a1b2c3d4e5f60718293a4b5c6d7e8f90",
  "recovery_ran": false,
  "recovered_boarding_addresses": 0,
  "recovered_boarding_utxos": 0,
  "recovered_vtxos": 0,
  "recovered_oor_receive_scripts": 0,
  "recovered_oor_events": 0
}
```

## Underlying RPC

Calls [`WalletService.Create`](/api/wallet/create/), which proxies the daemon's
seed generation and wallet initialization.
